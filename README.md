## 📝 Task Manager

Task Manager adalah aplikasi web sederhana yang memungkinkan pengguna untuk menambahkan, menghapus, dan menandai tugas sebagai selesai. Aplikasi ini dirancang untuk membantu pengguna dalam mengelola daftar tugas harian mereka dengan antarmuka yang intuitif dan responsif.

## 🚀 Fitur Utama

- ✅ Menambahkan tugas baru ke daftar.
- 🗑️ Menghapus tugas yang tidak diperlukan.
- ✔️ Menandai tugas sebagai selesai atau belum selesai.
- 💾 Penyimpanan data menggunakan Local Storage untuk mempertahankan data antar sesi.
- 🎨 Antarmuka pengguna yang responsif dan mudah digunakan.

## 🛠️ Teknologi yang Digunakan

- **HTML**: Struktur halaman web.
- **CSS**: Styling dan tata letak halaman.
- **JavaScript**: Logika aplikasi dan interaksi pengguna.

## 📂 Struktur Proyek
```
Task_Manager/ 
├── index.html 
├── style.css 
├── script.js 
└── README.md
```

## 🔧 Cara Menggunakan

1. Buka `index.html` di browser Anda.
2. Masukkan deskripsi tugas pada kolom input dan tekan Enter atau klik tombol "Tambah".
3. Tugas akan ditambahkan ke daftar dengan opsi untuk menandai sebagai selesai atau menghapusnya.
4. Status tugas akan disimpan di Local Storage, sehingga tetap tersedia saat halaman dimuat ulang.

## 📌 Catatan

- Pastikan browser Anda mendukung Local Storage untuk menyimpan data tugas.
- Aplikasi ini dirancang untuk penggunaan pribadi dan tidak memerlukan backend atau database eksternal.
